一、文档说明

本文档为公司新版进销存、财务、回款、开票、质量异议、多公司权限、业务闭环归档 最终业务需求。
内容包含：功能说明、业务规则、具体案例、落地位置、使用目的，可直接交付软件实施团队开发配置。

二、详细业务需求

1、销售管理里需要自动生成合同
2、采购管理里需要自动生成合同

3、多公司抬头管理（3-4家主体）权限隔离体系

1.业务说明

公司存在多家独立经营主体，所有采购、销售、财务、报销数据必须按公司抬头完全隔离，账套独立、数据独立、权限独立。
员工可授权多家公司权限，但不可跨公司查看数据。

2.包含权限体系

每家公司独立开通：

• 采购权限（下单、审核、入库、查询）

• 销售权限（开单、改价、客户管理）

• 财务权限（对账、应收应付查看）

• 报销权限（对应公司报销制度、审批流）

3.业务规则

1. 所有单据：采购单、销售单、报销单、回款、开票 必选公司抬头

2. A公司人员无法查看B公司订单与账务

3. 报销标准、审批流程跟随所属公司自动匹配

4.真实业务案例

我司拥有甲、乙、丙三家贸易抬头：

• 客户订单归属乙公司 → 销售单、出库、开票、回款全部自动归到乙账套

• 采购进货归甲公司 → 应付账款、成本全部归属甲

• 员工出差费用归属丙公司 → 按丙公司报销标准审批入账

5.落地模块

系统基础设置 → 多主体公司权限管理

5、商品成本价、销售价、交货方式（自提/送到）字段需求

1.业务说明

所有交易单据必须锁定三项核心数据：成本价、销售价、交货方式，用于精准核算毛利、区分物流成本。

2.字段定义

• 成本价：真实采购入库成本（系统自动带出，不可随意修改）

• 销售价：对客户实际成交单价

• 交货方式：二选一【客户自提 / 我方送货】

3.业务规则

1. 自提：无物流费、客户自行提货、出库简单

2. 送到：系统需可录入物流信息、产生物流成本、影响最终毛利

3. 所有订单、出库、报表必须携带该三个字段

4.真实案例

镀锡卷业务场景：

• 成本价：5200元/吨

• 老客户价：5380元/吨（客户自提）

• 新客户价：5400元/吨（我方送货）
系统自动区分：自提单毛利高、送货单需扣物流成本。

5.嵌入位置（重点）

1. 商品档案（默认基准价）

2. 销售订单（必填）

3. 出库单（自动继承）

4. 毛利报表、订单明细报表（可筛选）

6、财务开票绑定订单、回款绑定订单（业财一体）

1.业务说明

杜绝“无单开票、无单回款”，所有开票、回款必须溯源对应销售订单，实现每笔订单：可查已开、未开、已回、未回。

2.业务规则

1. 开票必须选择对应销售订单，开票金额 ≤ 订单未开票金额

2. 回款必须核销对应销售订单，精准冲抵应收

3. 每张销售订单自带：开票台账、回款台账

3.真实案例

销售订单：10吨货物，总金额54000元

• 第一次开票30000元 → 系统标记：已开票3万，剩余2.4万

• 客户回款25000元 → 系统自动核销该笔订单应收

• 随时可查：本单剩余未回款、未开票金额

4.价值

杜绝财务与业务对不上、杜绝乱开票、漏对账。


8、新增独立版块：【已完结业务闭环归档】

1.功能定义

专门存放 全流程100%结束 的完整业务：
采购入库 → 销售开单 → 商品出库 → 全额开票 → 全额回款
五环节全部完结，自动归档至此板块

2.使用目的（核心用途）

1. 区分在办业务与完结业务
日常订单列表只显示未做完的单，页面清爽不杂乱

2. 财务月底对账专用
一键导出全部完整闭环业务，核算真实毛利、真实营收

3. 溯源审计备查
任意一笔完结业务，可一键联查：采购、销售、出库、发票、回款全部记录

4. 风险排查
不在归档板块的单子 = 必有尾巴（未出库/未开票/欠款）

3.业务规则

1. 自动判定闭环，无需人工手动归档

2. 若已回款被撤销、发票作废 → 单据自动退出归档板块，重回待处理列表

3. 本板块只看不改、只查不增，纯归档台账

4.落地模块

独立导航菜单：已完结业务归档台账


9、新增独立版块：【质量异议管理】

1.功能定义

统一管理所有 采购来料质量问题、客户出货质量投诉，所有纠纷线上留痕、可追溯、可关联财务扣款。

2.区分两类异议

1. 供应商来料异议（进货质量问题、瑕疵、少重、不合格）

2. 客户销售异议（客户投诉、质量争议、色差、镀层问题）

3.核心字段

• 关联源单：采购单/销售单

• 问题类型

• 问题描述 + 图片附件

• 责任判定

• 协商处理方案（退货、补货、折价、扣款）

• 处理进度状态

• 最终结果、财务扣款项

4.真实业务案例

案例1：采购镀锡卷到货镀层不达标

• 新建质量异议单绑定原采购单

• 上传瑕疵图片

• 协商供应商扣款800元

• 财务自动关联应付账款扣款

案例2：客户收货反馈表面划痕

• 建立客户质量异议

• 协商折价减免客户应收1200元

• 全程留痕，避免后续扯皮

5.业务价值

1. 所有质量纠纷不再依赖微信、Excel

2. 可统计：哪个供应商质量差、哪个客户投诉多

3. 质量扣款直接联动财务应收应付，不漏账

6.落地模块

独立导航菜单：质量异议管理

三、整体系统逻辑总结

1. 多公司数据完全隔离，权限分开

2. 所有订单锁定成本、售价、送货方式，精准算利润

3. 开票、回款全部绑定订单，业财完全打通

4. 自动归档全部结束的业务，方便对账审计

5. 所有质量纠纷统一板块管理、可追溯、可扣款项
